# First real run: 2026-11-20 (free Colab T4)

**Preliminary.** Severity labels are LLM pre-labels (Phi-3.5-mini), not human labels, so
these numbers are for development only, not for the paper.

## Setup
- 1,125 queries (StakesQA seed sizes, see README); 10 Kanglish queries held out as a shift test
- Small: Qwen2.5-3B-Instruct · Large: Qwen2.5-14B-Instruct-AWQ · Judge and severity
  pre-labeller: microsoft/Phi-3.5-mini-instruct (ungated; no Llama licence on this account yet)
- alpha = 0.05, delta = 0.10, weights = (0, 0.1, 0.4, 1), 100 random splits, CRC calibration
- vLLM 0.34.0, torch 2.14, Tesla T4 15 GB

## Runtime (first full pass)
| Stage | Time |
|---|---|
| Setup (pip install vLLM etc.) | 3 min |
| Dataset (downloads + gcc for 250 programs) | 1.2 min |
| Small model, 1,125 answers (incl. download + load) | 3.5 min |
| Large model, 1,125 answers (incl. ~6 min download + load) | 14.6 min |
| Grade (judge on 421 open answers + 1,125 severity labels) | 6.4 min |
| Verify | 0.7 min |
| Evaluate, 100 splits (CPU) | 6.6 min |
| **Total** | **about 36 min** |

The first pass exposed a prompt bug: numeric and code-output answers were capped at
160 / 60 tokens and asked for the answer before any working, so the small model scored
15% on GSM8K and 1% on code output. After the fix (reason first, answer lines last,
512 / 400 tokens), only those 450 queries were regenerated (about 20 min).

## What this run says
1. **The pipeline works end to end in about 36 minutes**, and both guarantees hold empirically.
2. **alpha = 0.05 cannot be met without humans.** Even a perfect router over the two models
   reaches SWER 0.0547 (oracle), mostly because both models miss about 40% of MedMCQA
   (severity 3). So about 22% of queries are flagged, and humans dominate the cost.
3. **Stakes-awareness is NOT yet better than stakes-blind routing.** At matched cost, HSER is
   0.168 vs 0.175 (uniform risk) and 0.169 (stakes-blind ablation): within noise. Likely
   cause: the LLM pre-labels have little spread (71% are level 2), so there is little stakes
   signal to exploit. This is the central claim of the paper and it is unsupported until
   the human labels and a more varied dataset are in.
4. **Verification pays:** the same risk at 9% lower cost than without the verify action
   (1.82 vs 2.00 per 1k).
5. **The confidence cascade is useless with Qwen2.5-3B:** it reports CONFIDENCE 10 almost
   always, so the cascade sends everything to the large model.
6. **Kanglish shift breaks the guarantee** (SWER 0.18 on 10 queries): expected, and a
   finding worth reporting once the set has about 110 queries.
